# Product: Easier-to-navigate Twig modules

## Problem

When someone wants to change a behavior in Twig, it is not obvious where that behavior is implemented. They have to hunt through the project before they can get to work.

## Success metric

Reduce the median time to identify the implementation for five representative change tasks by at least 50%, measured by timing a contributor unfamiliar with those areas before and after the refactor.

## Announcement — the blog post before the feature

Finding your way around Twig should not be a scavenger hunt. We have reorganized the project so related behavior is easier to locate and the path from a feature to its implementation is clearer. This makes it quicker for contributors to understand existing code and make focused changes. The goal is simple: spend less time searching, and more time improving Twig.
