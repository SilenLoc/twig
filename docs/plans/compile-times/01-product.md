# Product: Faster compile times

## Problem

As a Twig contributor, I spend too much time waiting for builds to finish, which slows down the edit-run-feedback cycle. I want to find out whether simplifying the code can make that wait noticeably shorter.

## Success metric

Reduce the median time for a clean local build by at least 20% versus a baseline measured before changes, using the same machine and build conditions for five runs each.

## Announcement — the blog post before the feature

Twig contributors should spend less time waiting and more time working on the project. We’re looking for practical ways to shorten local build times without compromising correctness or maintainability. We’ll measure the change against a repeatable baseline and keep the improvement only if the results are real. The goal is a faster feedback loop for everyday development.
